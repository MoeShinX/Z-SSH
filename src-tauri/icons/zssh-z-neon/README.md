# Z-SSH 图标（Z- 荧光）

深色圆角底板上一个荧光绿的 Z（带柔和光晕），后面跟一道黄色的终端光标。
应用、安装器、卸载器都用这一套（见 `../../tauri.conf.json`）。

## 来源

字形取自一张内置 imagegen 生成的「Z-」设计稿（原稿不在仓库里）：按颜色把绿色 Z 和黄色短横抠出来，
换成纯色，放大到底板宽度的约 66% 并居中；底板重画成干净的纯色圆角，加一圈细的浅色描边；
光晕按固定半径重新生成（原稿的光晕带噪点）。

## 小尺寸

ICO 里 16、24 像素两帧单独做：标记放大到约 80%、不要光晕和描边（小尺寸里只会糊成一团），
任务栏小图标和标题栏也看得清；32 像素及以上和 PNG 都用标准版。

## 文件

- `logo-master.png`：1024 × 1024 主图，圆角外透明。
- `icon.ico`：16、24、32、48、64、256 六帧。
- `32x32.png`、`64x64.png`、`128x128.png`、`128x128@2x.png`、`icon.png`（512）。
