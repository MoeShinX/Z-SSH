# Z-SSH

面向 Windows 10/11 (x64) 的原生 SSH 客户端，集终端、SFTP 文件管理和 AI 运维助手于一体。后端 Rust（Tauri 2 + russh），界面 React + xterm.js。

- **AI 运维**：内置面板接入 opencode / Codex / Claude Code，用自然语言查看和操作服务器，命令直接在你的终端里执行，可以逐条确认后再放行。
- **数据在本机**：主机、凭据、设置都存在你自己的电脑上，密码和私钥口令用 Windows 数据保护接口（DPAPI）加密；需要多机同步时再自己选存储，云端只放密文。
- **轻量原生**：不依赖 Electron，当前用户安装，不需要管理员权限。

## 安全与隐私

**你的数据只在你自己手里，本项目不接触任何用户数据。**

- **没有账号、没有服务器、没有统计**：Z-SSH 不需要注册，项目方不运营任何收集数据的服务器；程序里没有使用统计、行为追踪或崩溃上报。
- **数据存在本机**：主机、凭据、设置、AI 对话记录都保存在你电脑上的数据目录（默认 `%APPDATA%\Z-ssh`）。密码、私钥口令、同步令牌用 Windows 数据保护接口（DPAPI）加密，只有你这个 Windows 账户能解开；日志里不记录任何凭据。
- **同步是端到端加密的**：只有你自己开启同步时才会上传，而且只传到你自己选的存储（WebDAV、S3、GitHub Gist 或你自己的 OneDrive）。上传前在本机用主密码加密，云端只有密文，主密码不会离开你的电脑。
- **程序只会连这些地址**：
  - 你自己添加的服务器，以及你配置的代理和跳板机；
  - 检查更新时访问 GitHub Releases（可在设置里关掉），更新包必须通过签名校验才会安装；
  - 你开启同步时的同步存储；登录 OneDrive 时直接跳转到微软官方登录页；
  - 一键下载 opencode 时访问它在 GitHub 上的发布页。
- **AI 功能用的是你自己的智能体**：Z-SSH 本身不调用任何 AI 服务，而是启动你自己安装并登录的 opencode / Codex / Claude Code。你在 AI 面板里的对话、AI 执行的命令和输出，会由这些智能体发给你在其中配置的模型服务商，适用他们的隐私条款。不用 AI 面板就不会有这部分流量。
- **开源可查**：所有代码都在这个仓库里，以上每一条都可以自己核对。

## 功能

### AI 运维助手

- **三种智能体**：opencode、Codex、Claude Code 任选（需自己先装好并登录）；面板里选模型和思考强度（opencode 的免费模型也能用，需要 opencode 1.18 以上；模型列表里免费的排在最前，其余按名字 A→Z），`@` 指定要操作的主机，随时可以停止。
- **命令在你的终端里执行**：AI 的命令经内置工具桥发到终端，你能看到每一步输出（终端正忙时改走后台通道）；也能读写远端文件。同一台主机只算一个目标；对话涉及多台主机时，工具卡片会标明在哪台执行，点「查看终端」切过去，AI 在没在看的标签里执行时标签上有紫色活动点；对话中切走终端，原来的主机仍留在 AI 的作用范围里（可手动移除）。
- **三档执行模式**：逐条确认 / 只读自动（查看类命令直接执行，会改动系统的仍要确认）/ 全部放行。
- **主机长期记忆**：AI 会记下主机的概况、服务和处理过的问题，下次对话自动带上；只存本机，敏感值会隐藏。
- **历史会话**：对话保存在本机（明文，可能含命令输出，可在设置里一键清空），重启后可回看，也可接着聊。
- **清爽的回复**：Markdown 按格式排版，执行完的命令合并成一行小字，点开才看详情。
- **安全措施**：逐条确认和只读自动模式下，会改动系统的命令要你批准（全部放行模式不再询问，按需选用）；含控制字符的命令一律拦下；只读自动对每个命令的参数按允许列表检查：不认识的参数、缩写的选项、合并写法里混着没列出的字母，一律要你确认，需要 shell 展开后才知道真实参数的写法（`$变量`、花括号、通配符、历史展开 `!`）也一样，能执行程序、写文件或改系统状态的用法不会被自动放行。

### 配置同步与备份

- **端到端加密同步**：主机库、凭据、代理、快捷命令和设置加密后同步到 WebDAV、S3 兼容存储、GitHub Gist 或 OneDrive；云端只存密文，主密码不上传。
- **多机合并**：多台电脑自动合并，防误删确认，冲突可恢复。
- **本地自动备份**：合并云端数据前、恢复前、升级后第一次启动时自动留一份加密快照，默认保留 20 份。
- **离线备份文件**：设置 → 同步里导出用密码加密的备份文件（含主机、凭据、代理、已信任指纹），导入时可合并或替换。

> OneDrive 目前只支持个人微软账号。官方发布的版本已内置应用 ID，点「用微软账号登录」即可，授权页会显示发布者「未验证」，这是个人开源项目没做微软发布者认证，属正常现象。自己从源码构建的版本需要自己的应用 ID，见下文。

### 主机管理

- **主机树**：分组和子分组、标签；树顶部有搜索框（输入即过滤名称 / 地址 / 用户名 / 标签，只显示匹配的主机和分组路径，↑↓ 选、Enter 连接、Esc 清空）；按名字排序（数字、英文、中文拼音），主机页卡片按最近打开排；拖动主机或右键「移动到分组」就能换分组；主机树在主机页和终端界面都在左侧，拖它的右边缘可以调宽度（双击恢复默认），顶部标签会和它对齐；单击主机，树底部会展开只读的属性面板（名称、地址、用户名、协议、端口，有跳板机 / 代理时再加一行），右键「编辑」打开主机详情。
- **快速连接**：直接输入 `user@host:port` 就能连，不用先建主机。
- **系统图标**：连上后自动识别 Debian、Ubuntu、CentOS、Rocky、Alpine 等发行版，主机树和卡片显示对应图标。
- **主机详情**：连不上或认证失败时自动弹出，方便直接改；AI 给主机记下的长期记忆也在这里查看、编辑。
- **新建默认值**：新建主机默认端口 22、用户名 root，都可以直接改。

### 认证与安全

- **多种认证方式**：密码、私钥（含口令）、Windows OpenSSH agent / Pageant、keyboard-interactive（两步验证）。
- **本机加密**：密码和私钥口令用 DPAPI 加密保存，日志里不记录任何凭据。
- **主机指纹校验**：首次连接要你确认指纹；指纹变化时直接阻断并提示；`known_hosts` 里标了 `@revoked` 的密钥一律拒绝。
- **生成 SSH 密钥和一键装公钥**：在凭据面板生成 Ed25519 / ECDSA / RSA 密钥，主机右键「安装公钥」一键追加到服务器的 `authorized_keys`，还能顺手改成密钥登录。默认不再用 SHA-1 的 ssh-rsa，连很老的服务器时在主机「高级」里打开兼容。

### 网络

- **SSH 代理和跳板机**：SOCKS5 / HTTP 代理（可设默认代理，新建主机默认不使用代理），支持多级跳板机。
- **软件网络代理**：检查更新、配置同步、下载 opencode 用的代理在「设置 → 连接 → 软件网络」单独设置，可选沿用 SSH 默认代理、跟随系统、不使用或指定代理。
- **端口转发**：本地（-L）和远程（-R）转发，按主机保存，可随终端自动开启；面板显示状态、连接数和流量。

### 终端

- **标签与分屏**：同一主机可开多个 shell；标签右键有重新连接、复制标签页、关闭其他等，双击终端标签也是复制标签页；断线自动检测，可一键重连。
- **终端里的网址**：悬停显示下划线，单击选中整条链接（Ctrl+C 复制），双击用系统默认浏览器打开，右键「打开链接 / 复制链接」；程序输出的超链接（显示文字和目标不同）也一样，打开和复制用目标网址；只放行 http / https。
- **多窗格输入广播**：Ctrl+Shift+B，键盘输入同时发到当前标签的所有分屏。
- **快捷命令栏**：底部一排常用命令按钮，单击发到当前窗格，Ctrl+单击发到所有分屏；空白处双击或右键直接新建；支持分组，可拖高成多行，随配置同步。
- **关键词高亮**：默认开启，给错误、警告、成功、IP、网址等关键词或自定义正则上色（可在设置里关闭或逐条开关），只标屏幕上的行、不改输出内容；浅色终端自动换深一号的颜色。
- **会话日志**：把每个终端会话存成纯文本日志（去掉颜色和光标控制），目录可选，默认关。
- **顺手的输入**：选中文字后 Ctrl+C 复制（没选中照常中断命令），Ctrl+V 粘贴；多行粘贴前先确认；终端里自动切到英文输入法，离开终端回到 AI 对话框、搜索框、编辑器等其他输入框时恢复你自己的中英文状态（终端里要临时打中文按 Ctrl+空格；设置里可关）。
- **主题和皮肤**：系统 / 浅色 / 深色三档，跟随 Windows 明暗切换，十多套应用皮肤可选；新装默认是深色 + Dracula 皮肤 + Tokyo Night 终端配色，终端配色也可以改成跟随皮肤或固定为某一套。

### 服务器状态

- **状态栏**：终端底部实时显示 CPU、内存、磁盘、网速、负载和开机时长，窗口窄了按优先级自动收起。
- **服务器概览**：点状态栏打开，看 CPU 型号和每个核心、内存、全部磁盘分区、网卡和网速曲线、开机以来的收发流量、内存占用前十的进程。复用状态栏的采集，不额外开连接。

### SFTP

- **双栏文件管理**：本地 / 远端左右两栏，也可作为停靠面板挂在终端旁（面板里的本地栏可以点 × 收起，只留远端栏，从标题栏的「本地」按钮请回来；「跟随终端目录」默认关闭，需要时自己勾上），或在独立的 **Z-SFTP** 文件窗口里打开；支持后退 / 前进（Alt+←/→、鼠标侧键）和直接输入路径（Ctrl+L）。关闭 Z-SFTP 窗口时默认断开里面的连接，也可以在「设置 → 外观 → 窗口」里改成把标签合并回主窗口，连接和传输都不中断。
- **传输队列**：上传下载、文件夹递归、冲突处理、断线续传，可从资源管理器拖入上传。遇到同名文件会弹窗询问，默认选中「覆盖」；队列里每一项可以右键重试 / 暂停 / 继续 / 取消，失败、已取消、已跳过的都能重试。
- **复制粘贴和属性**：Ctrl+C / V 复制文件，同一台服务器内直接在服务器上复制、不绕道本机，两台服务器之间经本机中转；本地和远端之间用上传 / 下载。Alt+Enter 看属性，文件夹可递归计算大小。
- **内置编辑器**：双击远端文本文件，用 CodeMirror 6 在标签里编辑保存；Ctrl+/ 切换行注释（配置文件按 `#`）；未保存的修改会定时存草稿，意外退出后能找回。

### 其他

- **自动更新**：签名校验，见下文。
- **单实例**：同一时间只开一个 Z-SSH（安装版和免安装版共用），再次打开会切到已有窗口。
- **托盘常驻**：点主窗口的 × 默认缩到右下角托盘，会话和转发继续运行；左键点托盘图标叫回窗口，右键「退出」才真正退出（设置里可改成点 × 直接退出）；退出时如果还有连着的终端、在跑的端口转发，或者 SFTP 标签、终端旁文件面板、Z-SFTP 里的 SFTP 连接，会先确认（连同未保存的编辑、进行中的传输合成一个对话框），没有就直接退出；缩在托盘时如果 AI 要你确认命令、新主机要确认指纹或要输入密码，会自动把窗口叫出来。
- **免安装版**：解压即用，见下文。

## 安装

到 [Releases](https://github.com/MoeShinX/Z-SSH/releases) 页面，下载最新版本里的文件，二选一：

- **安装版** `Z-SSH_<版本>_x64-setup.exe`：双击运行。按**当前用户**安装，不需要管理员权限，自带 AI 功能依赖的 `zssh-mcp.exe`，支持自动更新。
- **免安装版** `Z-SSH_<版本>_x64_portable.zip`：解压后运行 `Z-SSH.exe`；`zssh-mcp.exe` 要和它放在同一目录（AI 功能用）。

**首次运行 Windows 可能提示"Windows 已保护你的电脑 / 未知发布者"**：这是因为安装包没有购买代码签名证书，不代表有问题。点「更多信息」→「仍要运行」即可。如果担心，可以对照 Releases 页面上的说明自行从源码构建。

要求：Windows 10 / 11 x64，需要 WebView2 运行时（Windows 11 自带，Windows 10 缺少时安装程序会自动下载安装；免安装版需要系统里已有）。

数据默认保存在 `%APPDATA%\Z-ssh`（主机库、设置、已知主机指纹），安装版和免安装版用同一个目录。**卸载软件不会删除这个目录**，重装后数据还在。想换位置可以用环境变量 `ZSSH_DATA_DIR`。

## 自动更新

Z-SSH 每次启动后会检查一次 GitHub Releases 上有没有新版本，程序一直开着时每 6 小时再查一次（可在「设置 → 关于」里关掉；关掉后既不自动检查，也不自动下载安装）：

- 自动检查到新版本后，Z-SSH 会**在后台静默下载并校验签名**，下好后**弹一次窗口**告诉你：可以「立即重启安装」，手头有活没做完就选「稍后，退出时安装」，等你**退出 Z-SSH 时自动安装**，下次打开就是新版（安装完不会再把程序重新打开）。不会自己重启，不会打断正在用的 SSH 会话、传输和 AI 命令。被你「跳过」的版本不会自动下载。
- 在「设置 → 关于」手动点「检查更新」，查到新版本会弹出更新说明，可以选「立即更新」「稍后」或「跳过这个版本」；如果后台已经下好了，对话框会告诉你退出时会自动安装，也可以选「立即重启安装」。
- 更新包带有签名，下载后先校验签名（还要求签名里的版本号和公布的版本一致，防止被换成旧版本），校验不过就拒绝安装。
- 检查和下载走「设置 → 连接 → 软件网络」里设的代理（国内网络可以先设代理）。
- 重启安装前，如果还有文件传输、终端里正在执行的 AI 命令或编辑器里没保存的修改，会先提醒你。
- **免安装版**照常提示有新版本，但不会自动下载安装，只提供「打开下载页」，请下载新的 zip 覆盖原来的文件夹。
- 更新不需要管理员权限，不会动你的数据目录。

维护者发布新版本的步骤和更新签名密钥的说明见 [`docs/release.md`](docs/release.md)。

## 从源码构建

依赖：

- Rust stable（MSVC 工具链）与 Visual Studio 2022 C++ 生成工具
- Node.js 24 与 npm
- tauri-cli 2.x：`cargo install tauri-cli --version "^2"`
- WebView2 运行时（Windows 10/11 一般已自带）

不需要 CMake 或 NASM：`russh` 已关闭默认特性，使用 `ring` 后端。

```powershell
git clone https://github.com/MoeShinX/Z-SSH.git
cd Z-SSH

# 1. 安装前端依赖
cd ui
npm ci
cd ..

# 2. 开发模式（tauri-cli 会同时启动 Vite 前端和应用）
cargo tauri dev

# 3. 打 Windows 安装包（先编 zssh-mcp.exe，再 cargo tauri build）
powershell -File scripts/build-installer.ps1
```

安装包在 `target/release/bundle/nsis/` 下。自己构建的包没有更新签名，所以**自己构建的版本检查更新时会提示没有配置签名公钥**；这是预期的，只有官方发布的版本带更新签名。同理，自己构建的版本默认没有内置 OneDrive 应用 ID：构建前设环境变量 `ZSSH_ONEDRIVE_CLIENT_ID`，或在同步设置的「高级」里自己填（见 [`docs/release.md`](docs/release.md)）。

只想要 `Z-SSH.exe` 本体而不打安装包时，必须带 `custom-protocol` 特性（不带的话 exe 会去连开发服务器的 `localhost:1420`，直接打开会报连接拒绝）：

```powershell
cd ui
npm run build
cd ..
cargo build --release -p zssh --features custom-protocol
```

## 测试

```powershell
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
cd ui
npm test
npm run build
```

平时完整的门禁交给 CI 跑，本地改哪测哪即可，开发约定见 [`AGENTS.md`](AGENTS.md)。联网用例（SSH / 代理 / 跳板机 / AI）需要的连接信息全部来自环境变量；没有设置时相关用例自动跳过。完整的联网测试用 `powershell -File scripts/live-tests.ps1`；发布前用 `powershell -File scripts/privacy-scan.ps1` 扫一遍有没有带上个人信息。

自己动手把整个软件试一遍可以照着 [`docs/manual-test.md`](docs/manual-test.md)。
