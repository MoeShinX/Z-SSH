# Z-SSH 手测清单

这份清单是给你自己把整个软件从头到尾试一遍用的。程序里的自动化测试已经覆盖了大部分逻辑，但有些东西只有真人在真机器上点一点才能确认——**标了「重点」的条目就是这类**：之前只做过自动化测试、只对着模拟服务试过，或者只是按文档写的，从来没在真实环境里验证过。

## 怎么用

1. 每一项前面有个方框，测完打勾 `[x]`；没条件测的写"跳过"。
2. 「结果 / 备注」里随手记：看到了什么、哪里不对。有问题最好截图，截图时别把服务器地址、IP、用户名拍进去。
3. 每一组开头的「需要准备」写了这一组要用到什么。没有的东西，这一组里对应的条目可以直接跳过。
4. 条目里写"预期"的，就是正常应该看到的样子；和预期不一样就是问题。

## 要提前准备的东西（汇总）

| 东西 | 用在哪里 | 没有怎么办 |
| --- | --- | --- |
| 一台能用密码登录的 Linux 服务器（测试服务器） | 几乎所有连接、终端、SFTP、AI 的条目 | 没有就只能测主机库、设置、同步这几组 |
| 一把私钥文件（最好有一把带口令、一把不带口令） | 私钥登录 | 跳过私钥条目 |
| 一台开了"两步验证"（keyboard-interactive）的服务器 | 两步验证登录 | 跳过 |
| 本机的 SSH agent（Windows 的 OpenSSH Authentication Agent 服务，或 Pageant），里面加载了服务器认可的密钥 | agent 登录 | 跳过 |
| 一个能用的代理（例如本机的 SOCKS5 代理） | 代理 | 跳过 |
| 第二台能连上第一台服务器的服务器（或同一台服务器用另一个别名） | 跳板机 | 跳过 |
| 至少一个 AI 智能体：opencode、Codex、Claude Code 中的任意一个，已装好并登录 | AI 助手 | 跳过 |
| 一个 WebDAV 账号（坚果云、Nextcloud 等；最好有 https 地址） | 配置同步 | 跳过 |
| 一个 S3 兼容存储的桶和访问密钥（AWS、Cloudflare R2、MinIO、阿里云 OSS 等） | 配置同步 | 跳过 |
| 一个 GitHub 个人访问令牌（经典令牌勾 `gist` 权限，或细粒度令牌给 Gists 读写权限） | 配置同步 | 跳过 |
| 一个个人微软账号（outlook.com / hotmail.com 等，OneDrive 免费 5GB 就够）；发布版需要已经按 `docs/release.md` 注册 Azure 应用并编进 client ID，自己编译的版本在同步设置「高级」里填自己的 client ID | 配置同步里的 OneDrive | 跳过 |
| **第二台 Windows 电脑**（或第二个 Windows 用户账号，两个都装 Z-SSH 并用各自独立的数据） | 配置同步里"两台电脑" | 可以只在一台电脑上测，跳过"两台电脑"的条目 |
| 一些测试文件：几个小文件、一个几百 MB 的大文件、一个带中文名和空格的文件、一个文件夹（里面有子文件夹） | SFTP | 自己随便造 |

**提醒**：测试前最好备份一下你真实的数据目录（默认在 `%APPDATA%\Z-ssh`，在设置的"关于"页里可以点"打开所在文件夹"）。如果想完全不碰真实数据，可以用环境变量 `ZSSH_DATA_DIR` 指定另一个空目录再启动软件。

## 1. 安装与首次启动

**需要准备**：安装包（`Z-SSH_0.1.0_x64-setup.exe`）。

- [ ] **安装**：双击安装包，按提示一路下一步。预期：能装完；开始菜单里有 Z-SSH 的图标；安装过程没有报错。
  - 结果 / 备注：
- [ ] **首次启动**：从开始菜单启动。预期：窗口正常出现、图标和名称正确；只有"主机"页，没有空的终端标签；没有弹出任何错误。
  - 结果 / 备注：
- [ ] **窗口外观**：标题栏的最小化、最大化、关闭按钮都能用；窗口可以拖动、拖边缘改大小；双击标题栏最大化 / 还原。
  - 结果 / 备注：
- [ ] **关于页**：设置 → 关于。预期：名称 Z-SSH、版本 0.1.0；"开源许可"能打开，能看到第三方代码的署名说明。
  - 结果 / 备注：
- [ ] **重点 · 没有 WebView2 的电脑**（只有 Windows 10 旧系统才可能碰到）：如果有机会在没装 WebView2 的电脑上装，预期安装程序会提示或自动安装。没有这样的电脑就跳过。
  - 结果 / 备注：
- [ ] **重点 · 卸载**：设置 → 应用里卸载 Z-SSH。预期：软件被删除，但数据目录（`%APPDATA%\Z-ssh`，里面是你的主机库）**还在**。重新装回去以后，主机库还在。
  - 结果 / 备注：

## 3. 连接与认证

**需要准备**：测试服务器（密码登录）；私钥；两步验证服务器；SSH agent。

- [ ] **密码登录 + 指纹确认**：第一次连接，预期弹出主机指纹确认，选"信任并保存"后连上。断开再连，不再弹指纹。
  - 结果 / 备注：
- [ ] **保存密码**：主机没存密码时连接会弹密码框；勾选保存后，下次连接不再问。
  - 结果 / 备注：
- [ ] **输错密码**：预期提示认证失败，并且**错的密码不会被保存**（再连还会问）。
  - 结果 / 备注：
- [ ] **清除指纹**：主机详情的"高级"里点"清除已保存的指纹"，再连会重新询问指纹。
  - 结果 / 备注：
- [ ] **指纹变化**：把主机地址改成另一台服务器（或者让服务器重装 SSH 密钥），用同一个名字再连。预期：连接被阻断，并明确提示指纹变了，不会悄悄连上。没条件就跳过。
  - 结果 / 备注：
- [ ] **重点 · 私钥登录（不带口令）**：凭据里添加私钥文件，主机认证方式选私钥。预期：直接登录。
  - 结果 / 备注：
- [ ] **重点 · 私钥登录（带口令）**：用带口令的私钥。预期：连接时弹出口令框，输对能登录，输错提示失败。
  - 结果 / 备注：
- [ ] **重点 · agent 登录**：本机 SSH agent 里加载好密钥，主机认证方式选 agent。预期：能登录。agent 服务没开时，预期给出看得懂的提示而不是卡住。
  - 结果 / 备注：
- [ ] **重点 · 两步验证（keyboard-interactive）**：连接开了两步验证的服务器。预期：弹出问题框（例如"验证码"），回答后能登录。
  - 结果 / 备注：
- [ ] **断开重连**：见下面第 6 组。

## 4. 代理与跳板机

**需要准备**：一个可用的代理；第二台服务器（跳板机用）。

- [ ] **跟随默认代理**：代理里添加 SOCKS5 代理并设为默认，主机选"跟随默认代理"，预期能连上。
  - 结果 / 备注：
- [ ] **不用代理**：主机选"不用代理"，预期直连成功。
  - 结果 / 备注：
- [ ] **重点 · HTTP 代理**：添加一个 HTTP 代理（可带账号密码），主机选它。预期能连上；代理账号密码填错时提示"代理要求认证 / 密码不对"。
  - 结果 / 备注：
- [ ] **代理不可用**：代理地址填一个不存在的，预期很快报错，不会一直转圈。
  - 结果 / 备注：
- [ ] **跳板机**：主机 A 的跳板机选主机 B，连接 A。预期：状态显示"第 1/2 跳、第 2/2 跳"，最后连上 A；两跳的指纹各问一次。
  - 结果 / 备注：

## 5. 终端

**需要准备**：测试服务器。

- [ ] **基本使用**：输入命令、回车、Ctrl+C，显示正常。
  - 结果 / 备注：
- [ ] **全屏程序**：`vim`（或 `vi`）、`htop`（或 `top`）、`tmux`、`less` 显示正常，能正常退出，退出后终端恢复。
  - 结果 / 备注：
- [ ] **窗口大小**：拖动窗口改大小后执行 `stty size`，行列数和窗口匹配。
  - 结果 / 备注：
- [ ] **中文**：`echo 中文测试` 显示正常；**用中文输入法**输入中文，候选框位置在光标附近、回显正确。
  - 结果 / 备注：
- [ ] **重点 · 终端自动切英文（设置 → 终端里的开关打开，用微软拼音等中文输入法）**：
  1. 刚启动程序，点进终端：输入法是英文；点进 AI 输入框：**保持你原来的状态**（原来是中文就是中文），不会被强制成英文。
  2. 在 AI 输入框切成中文打几个字 → 点回终端：变英文 → 再点回 AI 输入框：回到中文。
  3. 快速来回点"终端 → AI 输入框 → 终端 → AI 输入框"几次，最后停在 AI 输入框时是中文。
  4. 开两个分屏终端，在它们之间切换：一直是英文，输入法指示不来回闪。
  5. 焦点在终端时切到别的程序再切回来点终端：英文；再点 AI 输入框：恢复原来的状态。
  6. 焦点在终端时在设置里关掉这个开关：输入法立即恢复原来的状态。
  7. **终端 → 点按钮 / 空白处 → AI 输入框**：先在 AI 输入框切成中文，再点进终端（英文），然后点一个按钮、标签、AI 面板或文件列表的空白处（此时输入法指示还是英文，属正常，在等输入框），最后点 AI 输入框：约半秒内回到中文。这一步要多试几遍，也试「终端 → 空白处 → 文件面板里的路径输入框 / 搜索框」。
  8. 同上，但在点按钮之后再点回终端：一直是英文，指示不闪。
  9. 终端 → AI 输入框 → 快速点搜索框或路径输入框：最后取得焦点的输入框恢复原来的模式；再试原来就是英文时，不能强制切成中文。
  10. 拖动分屏分隔条、调整 AI / SFTP 面板宽度、改变窗口大小后，重复第 2、7、9 步；输入法作用范围仍只跟随终端输入焦点。
  - 结果 / 备注（第三方输入法如百度、搜狗可能不认这个切换，不认就什么都不发生，请写明用的输入法）：
- [ ] **大量输出**：执行 `head -c 104857600 /dev/zero | base64` 刷屏。预期：窗口仍能拖动、能操作；按 Ctrl+C 一秒左右停下。`yes` 跑 10 秒后 Ctrl+C 同样能停。
  - 结果 / 备注：
- [ ] **复制粘贴**：选中文字，Ctrl+Shift+C 复制，Ctrl+Shift+V 粘贴到终端。设置里打开"选中即复制""右键粘贴"后再试一次。粘贴多行文字时的行为符合预期。
  - 结果 / 备注：
- [ ] **回看和搜索**：滚动回看历史输出；Ctrl+Shift+F 搜索文字。
  - 结果 / 备注：
- [ ] **标签**：`Ctrl+Shift+T` 新建标签，`Ctrl+Tab` 切换，关闭标签。同一台主机开两个标签，第二个不再问密码。
  - 结果 / 备注：
- [ ] **分屏**：`Ctrl+Shift+D` 左右分屏、`Ctrl+Shift+E` 上下分屏。预期：新窗格秒开、不再要密码，**原窗格里的内容还在**；拖分隔条调整大小，两边 `stty size` 跟着变；`Ctrl+Shift+W` 关闭窗格。
  - 结果 / 备注：
- [ ] **主题和字体**：设置里换界面主题、终端主题、字体、字号、行高、光标样式，已打开的终端立即生效。
  - 结果 / 备注：
- [ ] **重点 · 手动体验 vim / less**：用 AI 或手动在终端里长时间操作 vim / less，确认没有错位、残影（这个只有真人看得出来）。
  - 结果 / 备注：

## 8. AI 助手

**需要准备**：至少一个智能体（opencode、Codex、Claude Code），已装好并登录（登录状态在各自的命令行里完成）；测试服务器。**这些智能体会调用模型，可能消耗你的额度。**

- [ ] **打开面板**：连上服务器后按 `Ctrl+Shift+A`（或点标题栏的 AI 图标）。预期：右侧出现 AI 面板，能看到当前有哪些智能体可选；没装的会提示怎么装 / 去设置。
  - 结果 / 备注：
- [ ] **重点 · opencode**：选 opencode，发"看一下服务器的磁盘使用情况"。预期：它调用工具在终端里执行命令，结果回到对话里。没装 opencode 时，面板里点"下载"能自动下载安装。
  - 结果 / 备注：
- [ ] **重点 · Codex**：选 Codex，同样的问题。预期同上。
  - 结果 / 备注：
- [ ] **重点 · Claude Code**：选 Claude Code，同样的问题。预期同上。
  - 结果 / 备注：
- [ ] **手动确认模式**：执行模式选"手动"，让 AI 执行一个命令。预期：先弹确认，点同意才执行，点拒绝则不执行并告诉 AI。
  - 结果 / 备注：
- [ ] **自动确认模式**：执行模式选"自动"，让 AI 执行命令。预期：不再弹确认，直接执行（含危险命令，所以只在测试机上用）。切回"手动"后恢复确认。
  - 结果 / 备注：
- [ ] **@ 主机**：在输入框里输入 `@`，选择另一台主机。预期：AI 能在那台主机上执行命令（需要那台主机可连接）。
  - 结果 / 备注：
- [ ] **在终端里执行**：让 AI 执行 `echo hello`。预期：你在终端里能看到这条命令被执行了，而不是悄悄在后台。
  - 结果 / 备注：
- [ ] **停止**：让 AI 执行一个耗时的任务（例如 `sleep 60`），点停止按钮。预期：很快停下，终端里的命令被中断，面板里显示"已停止"。
  - 结果 / 备注：
- [ ] **文件工具**：让 AI "读一下服务器上 /etc/hostname"、"在 /tmp 下新建一个文件写入 hello"。预期：对话里出现文件操作卡片，写入类操作需要确认（手动模式下），文件内容正确。
  - 结果 / 备注：
- [ ] **新对话**：点"新对话"，上一轮的内容清空，AI 不再记得之前的话。
  - 结果 / 备注：
- [ ] **重点 · 智能体未登录 / 额度用完 / 网络断了**：让智能体处于未登录状态（或断网）后发消息。预期：给出看得懂的提示，不会一直转圈。
  - 结果 / 备注：
- [ ] **命令卡片折成一行**：让 AI 连续执行两条命令（例如 `uname -a`、`df -h`）再读一个文件。预期：执行完的调用在文字之间只显示一行淡色小字（如"执行了 2 条命令、读了 1 个文件"），默认收起；点一下展开成完整卡片（命令、退出码、执行位置、输出），再点收起。
  - 结果 / 备注：
- [ ] **折叠行里有失败**：让 AI 执行一条会失败的命令（例如 `ls /不存在`）。预期：这一行变成琥珀色并写明"其中 1 条失败"，仍然默认收起，展开后能看到退出码和输出。
  - 结果 / 备注：
- [ ] **等待批准的不折叠**：切到手动确认模式，让 AI 执行一条命令（或写一个文件）。预期：待批准的命令 / 写文件差异完整显示、带"执行 / 拒绝"按钮，不被折叠；点"执行"并跑完以后才并入折叠行。命令正在跑的时候显示一行"正在执行：…"，不会让人以为卡住了。
  - 结果 / 备注：

## 14. 自动更新

自动更新需要**两个不同版本的安装包**才能真正测到"装上新版并重启"：一个旧版（已安装）和一个更新的版本（发布在 GitHub 的 Releases 里，且已经发布、不是草稿）。自动化测试已经覆盖了"检查、下载、验签、签名不对会被拒绝、走代理"，**但没有覆盖真正安装并重启**，所以下面的 ✱ 项特别需要你手测。

**需要准备**：已安装的旧版本；发布了一个更新版本的 GitHub 仓库（`MoeShinX/Z-SSH` 的 Releases）；国内网络可能要先在「连接 → 默认代理」里设好代理。

- [ ] **关于页的检查更新**：设置 → 关于，点「检查更新」。预期：显示"正在检查…"，然后是"已经是最新版本"或"发现新版本 vX.Y.Z"；没网络时显示看得懂的原因（例如"无法连接到更新服务器"），不影响继续使用。
  - 结果 / 备注：
- [ ] **启动时自动检查**：设置 → 关于里"启动时自动检查"打开，发布一个新版本后重启软件，等一会儿。预期：**没有弹窗，底部也没有提示**，后台悄悄下载（关于页能看到进度条和"已下载好，退出 Z-SSH 时自动安装"）；关掉开关后重启，不再检查也不下载。
  - 结果 / 备注：
- [ ] **新版本详情**：先把开关关掉、发布新版本后在关于页手动点「检查更新」。预期：直接弹出对话框，看到版本号和更新说明，三个按钮：立即更新、稍后、跳过这个版本。
